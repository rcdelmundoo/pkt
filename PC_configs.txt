=====================================
How to Configure in Packet Tracer:
=====================================

1. Click on each PC
2. Go to Desktop tab
3. Click "IP Configuration"
4. Select "Static" 
5. Enter the IP Address, Subnet Mask, and Default Gateway
6. Click anywhere to apply settings

OR use Command Prompt:
1. Click PC → Desktop → Command Prompt
2. Type: ipconfig /ip [IP] [Subnet Mask] [Default Gateway]
   Example for PC1: ipconfig /ip 192.168.1.2 255.255.255.128 192.168.1.1
